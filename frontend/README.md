# دليل البدائل — منصة فحص المنتجات

منصة توعوية مستقلة (PWA) تساعدك على مقاطعة الشركات الداعمة للاحتلال واستكشاف البدائل الوطنية والآمنة.

## المزايا

- **الماسح الذكي**: امسح الباركود لتعرف فوراً حالة المنتج (مقاطعة / بديل آمن).
- **قائمة المقاطعة**: قاعدة بيانات موثّقة للمنتجات والمحلات والشركات مع البدائل.
- **مقالات توعوية**: محتوى تحليلي يعمل دون اتصال.
- **Offline-first**: تعمل المنصة بدون إنترنت عبر Dexie وتتم المزامنة تلقائياً عند عودة الاتصال.
- **مساهمات المجتمع**: أضف منتجات جديدة واقترح بدائل، وتراجع الإدارة عنها قبل النشر.

## التقنيات

- **الواجهة الأمامية**: React + Vite + Tailwind CSS + vite-plugin-pwa
- **البيانات المحلية**: Dexie / dexie-react-hooks
- **الخلفية**: Django REST Framework (جذر المشروع)

## التشغيل

```bash
# الواجهة الأمامية
cd frontend
npm install
npm run dev        # تطوير
npm run build      # إنتاج
npm run preview    # معاينة البناء
npm run lint       # فحص الكود
```

## البيئة

اضبط رابط الـ API عبر متغير البيئة `VITE_API_BASE_URL` (الافتراضي: `http://127.0.0.1:8000/api/v1`).
